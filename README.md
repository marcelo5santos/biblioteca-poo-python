# Biblioteca POO Python

Projeto desenvolvido para estudo de Programação Orientada a Objetos (POO) utilizando Python.

## Objetivos

* Praticar classes e objetos
* Aplicar conceitos de encapsulamento
* Utilizar Git e GitHub profissionalmente
* Evoluir o projeto através de versões documentadas
* Construir portfólio de projetos Python

## Funcionalidades atuais

* Cadastro de livros
* Cadastro de usuários
* Listagem de livros
* Listagem de usuários
* Empréstimo de livros

## Estrutura do projeto

```text
models/
├── biblioteca.py
├── livros.py
└── usuarios.py

utils/
└── menu.py

main.py
```
